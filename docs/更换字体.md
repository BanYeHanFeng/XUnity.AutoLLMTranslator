## 判断 Unity 版本
- 找到日志文件`游戏根目录/BepInEx/LogOutput.log`，没有的运行一下游戏就会生成
- 搜索 Running under Unity，搜索到后V后面的数字就是版本号

## 下载 TMP 字体
[下载](https://github.com/sorrowmoil/sorrowmoil-MoeFont-for-XUnity.AutoTranslator/releases)
- 根据 unity 版本下载对应字体
- 选择一种字体，解压到游戏根目录，并记录文件名

## 修改配置文件
- 文件所在`游戏根目录/BepInEx/config/AutoTranslatorConfig.ini`
- 搜索`[Behaviour]`，搜索到后根据下方说明修改
```ini
[Behaviour]
FallbackFontTextMeshPro=文件名
```
- 查看是否解决，如未解决，根据下方说明修改
- 注：OverrideFontTextMeshPro 会导致部分游戏排版失效，建议在上面失效后才使用
```ini
[Behaviour]
OverrideFontTextMeshPro=文件名
FallbackFontTextMeshPro=文件名
```
