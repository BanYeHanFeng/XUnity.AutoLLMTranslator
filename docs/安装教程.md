## 安装 BepInEx 框架
[下载](https://github.com/BepInEx/BepInEx/releases)
- 根据电脑架构选择win_x64还是win_x86，一般选择win_x64
- 下载完后解压到游戏根目录，就算安装完成

## 安装 XUnity.AutoTranslator 框架
[下载](https://github.com/bbepis/XUnity.AutoTranslator/releases)
- 下载开头为XUnity.AutoTranslator-BepInEx
- 解压到游戏根目录，就算安装完成

## 安装 XUnity.AutoLLMTranslator 插件
[下载](https://github.com/BanYeHanFeng/XUnity.AutoLLMTranslator/releases)
- 下载开头为XUnity
- 下载完后放在`游戏根目录/BepInEx/plugins/XUnity.AutoTranslator/Translators/`，放完后就算安装完成

## 配置 XUnity.AutoLLMTranslator 插件
- 先启动游戏，框架会生成配置文件，生成完后结束游戏
- 修改配置文件，`游戏根目录/BepInEx/config/AutoTranslatorConfig.ini`
- 搜索并修改3处地方
```ini
[Service]
Endpoint=AutoLLMTranslate
FallbackEndpoint=
```
```ini
[General]
Language=目标语言，如zh
FromLanguage=原文语言，如ja
```
```ini
[AutoLLM]
Model=模型名字
URL=接口地址
APIKey=接口密钥
```
- 修改完后启动游戏看是否生效，如正常翻译则配置成功
