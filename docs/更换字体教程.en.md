## Determine Unity Version
- Locate the log file at `GameRoot/BepInEx/LogOutput.log`. If it doesn't exist, run the game once to generate it.
- Search for `Running under Unity`. The version number follows the letter `V`.

## Download TMP Fonts
[Download](https://github.com/sorrowmoil/sorrowmoil-MoeFont-for-XUnity.AutoTranslator/releases)
- Download the appropriate font based on your Unity version
- Choose one of the fonts you like, extract it to the game root directory, and note down the filename

## Modify Configuration File
- The configuration file is located at `GameRoot/BepInEx/config/AutoTranslatorConfig.ini`
```ini
[Behaviour]
OverrideFont=
OverrideFontSize=0.9, Font size
OverrideFontTextMeshPro=Font name, If layout errors occur, fall back to OverrideFont
FallbackFontTextMeshPro=Font name, Fallback font used when the primary font lacks certain characters
```
