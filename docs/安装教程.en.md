## Note
- This plugin currently does not support IL2CPP; adaptation may come in the future.

## Install BepInEx Framework
[Download](https://github.com/BepInEx/BepInEx/releases)
- Choose `win_x64` or `win_x86` based on your system architecture; generally choose `win_x64`
- After downloading, extract to the game root directory. Installation is complete.

## Install XUnity.AutoTranslator Framework
[Download](https://github.com/bbepis/XUnity.AutoTranslator/releases)
- Download the file starting with `XUnity.AutoTranslator-BepInEx` (without the IL2CPP suffix)
- Extract to the game root directory. Installation is complete.

## Install XUnity.AutoLLMTranslator Plugin
[Download](https://github.com/BanYeHanFeng/XUnity.AutoLLMTranslator/releases)
- Download the file starting with `XUnity`
- Place it in `GameRoot/BepInEx/plugins/XUnity.AutoTranslator/Translators/`. Installation is complete.

## Configure XUnity.AutoLLMTranslator Plugin
- First launch the game; the framework will generate configuration files. Close the game after generation.
- Edit the configuration file at `GameRoot/BepInEx/config/AutoTranslatorConfig.ini`
- Search for `[Service]` and modify it as shown below:
```ini
[Service]
Endpoint=AutoLLMTranslate
FallbackEndpoint=
```

- Search for `[General]` and modify it according to the instructions below:
```ini
[General]
Language=Target language, e.g., zh
FromLanguage=Source language, e.g., ja
```

- Search for `[AutoLLM]` and modify it according to the instructions below:
```ini
[AutoLLM]
Model=Model name
URL=API endpoint
APIKey=API key
```
- After modification, launch the game to verify if it works. If translation is functioning correctly, the configuration is successful.
