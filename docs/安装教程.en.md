## Install BepInEx Framework
[Download](https://github.com/BepInEx/BepInEx/releases)
- Choose `win_x64` or `win_x86` based on your system architecture. Generally, choose `win_x64`
- After downloading, extract to the game root directory. Installation is complete.

## Install XUnity.AutoTranslator Framework
[Download](https://github.com/bbepis/XUnity.AutoTranslator/releases)
- Download the file starting with `XUnity.AutoTranslator-BepInEx`
- Extract to the game root directory. Installation is complete.

## Install XUnity.AutoLLMTranslator Plugin
[Download](https://github.com/BanYeHanFeng/XUnity.AutoLLMTranslator/releases)
- Download the file starting with `XUnity`
- After downloading, place it in `GameRoot/BepInEx/plugins/XUnity.AutoTranslator/Translators/`. Installation is complete.

## Configure XUnity.AutoLLMTranslator Plugin
- Start the game first; the framework will generate configuration files. Close the game after generation.
- Edit the configuration file at `GameRoot/BepInEx/config/AutoTranslatorConfig.ini`
- Find and modify 3 sections:
```ini
[Service]
Endpoint=AutoLLMTranslate
FallbackEndpoint=
```
```ini
[General]
Language=Target language, e.g., zh
FromLanguage=Source language, e.g., ja
```
```ini
[AutoLLM]
Model=Model name
URL=API endpoint URL
APIKey=API key
```
- After modifying, start the game to verify it works. If translation is functioning correctly, the configuration is successful.
