## Determine Unity Version
- Locate the log file at `GameRoot/BepInEx/LogOutput.log`. If it doesn't exist, run the game once to generate it.
- Search for "Running under Unity". The number after the "V" is the version number.

## Download TMP Font
[Download](https://github.com/sorrowmoil/sorrowmoil-MoeFont-for-XUnity.AutoTranslator/releases)
- Download the corresponding font based on your Unity version
- Choose a font, extract it to the game root directory, and note down the filename

## Modify Configuration File
- File location: `GameRoot/BepInEx/config/AutoTranslatorConfig.ini`
- Search for `[Behaviour]` and modify it as shown below:
```ini
[Behaviour]
FallbackFontTextMeshPro=filename
```
- Check if the issue is resolved. If not, modify as shown below:
- Note: `OverrideFontTextMeshPro` may cause layout issues in some games. It is recommended to use it only if the above method doesn't work.
```ini
[Behaviour]
OverrideFontTextMeshPro=filename
FallbackFontTextMeshPro=filename
```
